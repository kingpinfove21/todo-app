# To-Do App

A simple to-do application built for HNG15 Task One.

## Features
- Add a task
- Mark a task as complete
- Delete a task
- Persist tasks across page reloads

## Tech Stack
- Next.js + Tailwind CSS
- localStorage for persistence

## How to Run
1. Clone the repo
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:3000`
